База данных статистики матчей в CS, с типами сущностей:Player, PlayerProfile, Team, TeamMembership, Tournament, Match, Map, MapVeto, MatchMap, PlayerMapStats, Weapon, PlayerWeaponStats


CS-Matches — реляционная база данных для хранения, агрегации и аналитики статистики киберспортивных матчей в дисциплине Counter-Strike.

Перечень сущностей:

Player — общая информация об игроках (никнейм, имя, страна, текущая команда).

PlayerProfile — расширенные данные профиля игрока (конфигурация настроек, девайсы, ссылки на соцсети, био).

Team — киберспортивные организации / команды (название, тег, регион, дата создания).

TeamMembership — история переходов игроков по командам с указанием дат вступления и ухода (позволяет отслеживать состав в конкретный момент времени).

Tournament — турниры и чемпионатные серии (название, призовой фонд, даты проведения, статус).

Match — отдельные матчи между командами в рамках турниров (дата, этап, формат BO1/BO3/BO5, победитель).

Map — справочник доступных игровых карт (Dust2, Mirage, Inferno и т.д.).

MapVeto — процесс вето (банов и пиков) карт командами перед матчем.

MatchMap — детали конкретной сыгранной карты в рамках матча (счет по раундам за сторону защиты/атаки, победитель карты).

PlayerMapStats — индивидуальная статистика игрока на конкретной карте матча (убийства, смерти, ассисты, рейтинг, ADR).

Weapon — справочник игрового оружия и гранат.

PlayerWeaponStats — статистика использования конкретного оружия игроком за матч/карту (урона нанесено, точность, хедшоты).Структура репозитория

Согласно требованиям проекта, репозиторий организован(будет :) )следующим образом:
./schemas — концептуальная, логическая и физическая схемы БД (в форматах PNG/PDF).
./data — CSV-файлы с данными 
./base_part — скрипты создания БД, заполнения и 15 нетривиальных SELECT-запросов (с использованием JOIN, подзапросов и оконных функций).
./advanced_part — скрипты для дополнительных этапов (индексы, представления, хранимые процедуры/функции, триггеры и версионность данных SCD).
